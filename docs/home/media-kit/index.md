# Media kit

This page gives the logos, the colors, and the fonts of Autoware. Use them for slides, posters, diagrams, and web pages about Autoware.

## Logos

Each logo comes in black, for light backgrounds, and in white, for dark backgrounds. The SVG files scale to any size. The PNG files are 2048 pixels on their longer side, with a transparent background.

- Keep the proportions of the logo. Do not stretch, rotate, or crop it.
- Keep free space around the logo, so that no other element touches it. The free space is two times the gap between the mark and the name.
- Use the black logo on light backgrounds, and the white logo on dark backgrounds.
- Do not change the color of the logo, and do not add effects such as shadows or gradients.

### Gradient

The gradient goes from indigo to cyan to green. Use it only for thin lines and small accents. Text and large areas stay on flat colors.

<div class="aw-gradient-bar" role="img" aria-label="A gradient from indigo through cyan to green"></div>

```css
linear-gradient(90deg, #3f2ee3, #00c8ff 55%, #00e678)
```

### Contrast

Text must have a contrast ratio of 4.5:1 or more with its background, and large text and icons 3:1 or more. These limits come from the [Web Content Accessibility Guidelines 2.2](https://www.w3.org/TR/WCAG22/#contrast-minimum), level AA. The table gives the contrast of each brand color on white and on navy.

| Color   | On white | On navy | Use as text                         |
| ------- | -------- | ------- | ----------------------------------- |
| Indigo  | 7.7:1    | 2.6:1   | On light backgrounds only           |
| Cyan    | 2.0:1    | 10.4:1  | On dark backgrounds only            |
| Green   | 1.7:1    | 12.2:1  | On dark backgrounds only            |
| Crimson | 5.0:1    | 4.1:1   | On light backgrounds, or large text |
| Navy    | 20.3:1   | 1.0:1   | On light backgrounds only           |
| Mist    | 1.1:1    | 18.7:1  | On dark backgrounds only            |

### Colors for icons and borders

Cyan and green are too light on a white background. Indigo and crimson are too dark on navy. For icons, borders, and large text, this site uses a darker or a lighter version of each color. All of them have a contrast of 3:1 or more on their background.

| Color   | On light backgrounds | On dark backgrounds |
| ------- | -------------------- | ------------------- |
| Indigo  | `#3f2ee3`            | `#8a7dff`           |
| Cyan    | `#0098c7`            | `#00c8ff`           |
| Green   | `#00a352`            | `#00e678`           |
| Crimson | `#dc143c`            | `#ff7076`           |
| Grey    | `#6b6f8a`            | `#9a9dbb`           |

## Fonts

- [Roboto](https://fonts.google.com/specimen/Roboto) for text.
- [Roboto Mono](https://fonts.google.com/specimen/Roboto+Mono) for code.

## Use the colors in this site

The colors are CSS custom properties in [`docs/assets/css/theme.css`](https://github.com/autowarefoundation/autoware-documentation/blob/main/docs/assets/css/theme.css), for example `--aw-indigo`. Use these properties, not the hex values, so that a page also follows the dark mode. The diagrams have rules of their own in [`tools/diagrams/README.md`](https://github.com/autowarefoundation/autoware-documentation/blob/main/tools/diagrams/README.md).
