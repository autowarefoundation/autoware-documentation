# Reference HW Design

This document describes the sensors and systems that work with Autoware, and gives additional information about them.

All equipment listed in this document has available ROS 2 drivers and has been tested by one or more of the community members on field in autonomous vehicle and robotics applications.

The listed sensors and systems are not sold, developed or given direct technical support by the Autoware community. You can ask about ROS 2 and Autoware issues with this hardware as described in the [support guidelines](../../community/support/support-guidelines.md).
