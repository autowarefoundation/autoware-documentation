## Description

This API provides the interface version of the set of AD APIs.
It follows [Semantic Versioning][semver] in order to provide an intuitive understanding of the changes between versions.
Autoware 2.0.0 returns the version 1.9.1. See the [release notes](../release.md) for the changes of each version.

The interface version is not the same as the version of the `autoware_adapi_msgs` package, which has its own release cycle.
