# Autoware system capabilities

Autoware offers a complete suite of capabilities for autonomous driving system development:

<div class="aw-features" markdown>

- :fa-cl-s fa-car-side: **Key components for AD systems**

  Autoware provides various algorithms for localization, obstacle detection, path planning, and vehicle control for users to choose depending on their needs. See the [components](autoware-architecture-v1/components/sensing/index.md).

- :fa-cl-s fa-microchip: **Hardware integration**

  Autoware provides reference implementations and instructions for integrating with different sensors and vehicles. See the [reference design](../reference-design/index.md).

- :fa-cl-s fa-vr-cardboard: **Simulation support**

  Autoware works with simulation platforms to validate algorithms and scenarios before real-world deployment. See the [quick start demos](../demos/index.md).

- :fa-cl-s fa-toolbox: **Tools**

  Autoware provides useful tools for development, including sensor calibration, mapping, data creation, diagnostics, and scenario tests.

</div>
